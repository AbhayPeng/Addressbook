# Address Book Management System in C

Project Overview
Developed a menu-driven Address Book application using C to manage contact information efficiently. The application supports creating, searching, editing, deleting, sorting, and displaying contacts, with file handling to preserve contact details between program executions.

Features
- Create Contacts: Add names, phone numbers, and email addresses.
- Search Contacts: Search by name, phone number, or email.
- Edit & Delete: Update or remove existing contacts.
- Sort Contacts: Sort by name, phone number, or email.
- Input Validation: Validate contact details and prevent duplicates.
- File Handling: Save and load contacts using a CSV file.
- Menu-Driven Interface: Simple command-line interaction.

Technologies Used
- Language: C
- Concepts: Structures, Pointers, Functions, Arrays, File Handling, String Manipulation
- Algorithms: Bubble Sort
- Storage: CSV file

Project Structure
- `main.c` – Main menu and program execution.
- `contact.c` – Contact management operations.
- `contact.h` – Structures and function declarations.
- `search.c` – Contact searching.
- `valid.c` – Input validation and duplicate checking.
- `unique.c` – Contact uniqueness checks.
- `sort.c` – Sorting operations.
- `display.c` – Formatted contact display.
- `file.c` / `file.h` – File storage and retrieval.
- `populate.c` / `populate.h` – Contact initialization support.
- `Contact.csv` – Contact data storage.

## Key Learnings
Gained practical experience in modular C programming, data structures, pointers, input validation, sorting algorithms, and persistent file handling.
